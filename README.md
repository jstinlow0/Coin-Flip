# Coin Flip

A tiny coin-flip app for your phone. Tap **FLIP** (or the coin) for heads or tails.

## Put it on your phone
1. In the repo on GitHub: **Settings → Pages → Deploy from branch**, pick this branch, folder `/ (root)`, Save.
2. Open the Pages URL on your phone.
3. **iPhone (Safari):** Share → *Add to Home Screen*. **Android (Chrome):** ⋮ → *Add to Home screen* / *Install app*.

It opens full-screen like an app and works offline.
