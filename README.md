# Coin Flip

A tiny coin-flip app for your phone. Tap **FLIP** (or the coin) for heads or tails.

## Put it on your phone
1. In the repo on GitHub: **Settings → Pages → Deploy from branch**, pick this branch, folder `/ (root)`, Save.
2. Open the Pages URL on your phone.
3. **iPhone (Safari):** Share → *Add to Home Screen*. **Android (Chrome):** ⋮ → *Add to Home screen* / *Install app*.

It opens full-screen like an app and works offline.

## Android home-screen widget
The `android/` folder is a real Android widget: tap the coin on your home screen to flip it.

**Install:**
1. On your phone, open this repo's **Releases** page → *Coin Flip widget (latest)* → tap **CoinFlip.apk**.
2. Allow your browser to install unknown apps when Android asks.
3. Long-press your home screen → **Widgets** → **Coin Flip**, drag it onto the screen (or open the Coin Flip app and tap *Add widget to home screen*).

GitHub Actions rebuilds the APK automatically whenever `android/` changes.
